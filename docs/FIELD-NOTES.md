## 关键发现（已固化为规则或测试）

1. **Package Cache 可能是显卡驱动**：D 机 11.30 GB 全部为 Intel 图形驱动旧包，readme 可判定。
2. **回收站可能藏巨物**：D 机 7.03 GB 中 3 GB 是 2021 年的 USMT.PPKG。
3. **WinSxS 清理后当日可用空间可能下降**：CBS 日志 + WinSxS\Temp 需重启释放；但目录本身确实缩小（C 机 29.47 → 22.50 GB）。
4. **提交量接近上限时不要缩页面文件**：否则系统 OOM 或强制撑大其他盘页面文件。
5. **快速启动与休眠绑定**：快速启动开着时关休眠会同时关闭快速启动。

## 真机回归记录

### 2026-10-24 机器 E（Augenstern / LAPTOP-TC3FKDD7）

- 方式：打包 `engine/` + `catalog/`（56 KB）→ scp → 远程解压 → `CDRIVE_HOME` 指向临时目录 → 只读跑 `probe --set intake` 与 `summary`
- 环境：Win11 家庭版 26300、管理员会话、PowerShell 5.1、无 WizTree
- 耗时：首轮 38.7 秒（17 探针），次轮 16.8 秒（文件系统缓存命中）
- 结果：

| 域 | 结论 |
|---|---|
| 磁盘 | C: 30.7 GB / 98.7 GB 可用（已用 68.9%） |
| 启动 | 启动项 21 个（可禁用 5），性能 ok |
| 更新 | 待重启：是 |
| 网络 | 网卡 3（Up 1），代理一致 |
| 安全 | 修复后 ok（修复前误判 BitLocker） |
| 恢复 | poor（无还原点、无卷影副本） |
| 备份 | ok（OneDrive 文件夹备份） |
| 外设 | 打印机 8 台，其中 2 台异常 |

- **抓到 2 个本机测不出的缺陷**：
  1. `--set` 等双横线参数在**直接调用**脚本时绑定失败（只有 `powershell -File` 模式才生效），而 SKILL.md 与全部 playbook 写的都是双横线写法
  2. Windows **家庭版不支持 BitLocker**，却被判为「未保护」，导致安全裁决误报 attention
