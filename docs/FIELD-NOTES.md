## 关键发现（已固化为规则或测试）

1. **Package Cache 可能是显卡驱动**：D 机 11.30 GB 全部为 Intel 图形驱动旧包，readme 可判定。
2. **回收站可能藏巨物**：D 机 7.03 GB 中 3 GB 是 2021 年的 USMT.PPKG。
3. **WinSxS 清理后当日可用空间可能下降**：CBS 日志 + WinSxS\Temp 需重启释放；但目录本身确实缩小（C 机 29.47 → 22.50 GB）。
4. **提交量接近上限时不要缩页面文件**：否则系统 OOM 或强制撑大其他盘页面文件。
5. **快速启动与休眠绑定**：快速启动开着时关休眠会同时关闭快速启动。
