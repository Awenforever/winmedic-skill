# 定位：主治医生，不是护工

> WinMedic 是 **DSH Agent 的 Skill**。它的价值不在「能删多少垃圾」，而在**能替人解决别人解决不了的问题**。

## 两个角色

| 护工（传统电脑管家） | 主治医生（WinMedic） |
|---|---|
| 按清单擦一遍 | 找病因再决定动不动 |
| 只会清缓存 | 会看病程、会调器械、会写病例 |
| 做完就结束 | 处置后可验证、可回滚、可复盘 |
| 单机、被动 | 能到远端、能长期随访 |

## 四层职责（不要混）

| 层 | 负责 | 不负责 |
|---|---|---|
| **引擎** | 事实（体积/介质/路径/声明路径）、护栏（红线/隔离区/WAL/审计） | **不下结论** |
| **DSH** | 判断病因、决定方案、说明理由 | 不自己造命令、不绕过护栏 |
| **Skill** | 强制走完决策流程、不许跳过 | 不替 DSH 思考 |
| **器械** | WizTree / DISM / netsh / pnputil / winget / 厂商安装器 | 不被自动执行高危动作 |

## 四件结构性能力

1. **远程能到**（`remote`）：把只读探针送到远端，证据带回本地，来源打 `origin` 标记
2. **病程能看**（`trend`）：只追加时间序列；样本不足就明说，不外推
3. **病因能排**（`diagnose`）：假设 × 指标 × 信号表，**不给结论**
4. **经验能留**（`cases/`）：七段式病例，可复现、可交接

## 「超越」的判据

不是和 CCleaner 比规则数量，而是和**「用户自己排查两小时」**比：

| 判据 | 目标 |
|---|---|
| 更快锁定病因 | 一次采集 + 鉴别诊断表，而不是逐个猜 |
| 不漏 | 清单强制覆盖（红线、热/冷、先装后搬、五层代理） |
| 可复现 | 每条结论都有证据与来源 |
| 可交接 | 病例库 + 审计日志，换人或换会话都能接上 |

## 不做什么

- 不做 GUI、不做安装包、不做注册表清理
- 不做清理规则军备竞赛
- 不收集遥测
- **不制造不可逆损害**：红线不因用户请求放开，`--purge` 需双确认 + 令牌子
