# 驱动与设备异常

## 适用
「设备管理器有黄叹号」「没声音」「网卡不见了」「打印机装不上」。

## Step 1: 只读取证

```powershell
.\engine\winmedic.ps1 probe --set updates
```

读 `probe.drivers`：
- `problemDevices`：名称 + 错误码 + 人话解释
- `gpuDrivers`：当前显卡驱动版本与日期

## Step 2: 按错误码处理

| 错误码 | 含义 | 处理 |
|---|---|---|
| 28 | 驱动未安装 | 装厂商驱动，不要用「自动搜索」 |
| 43 | 设备报告故障被停止 | 断电重启；仍失败则硬件可能有问题 |
| 10 / 31 | 无法启动 / 加载失败 | 卸载设备（勾选删除驱动）后重扫 |
| 12 | 资源冲突 | 查 IRQ/IO 冲突，多见于老设备 |
| 22 | 设备被禁用 | 启用即可 |

## Step 3: 驱动来源优先级

1. **厂商官网对应型号**（最稳）
2. Windows Update 的可选驱动
3. 芯片厂商通用驱动（Intel/AMD/NVIDIA）

**不要用第三方驱动大师**——捆绑与版本错配是常见故障源。

## Step 4: 回滚路径

设备管理器 → 属性 → 驱动程序 → **回退驱动程序**（仅在有上一版时可用）。
装驱动前先建还原点，尤其是网卡/存储控制器驱动。

## Step 5: 红线

- 不动存储控制器驱动（失败会导致进不了系统）
- 不在没有备份的情况下刷 BIOS
- 不为了「清空间」删 `C:\Windows\System32\DriverStore`
