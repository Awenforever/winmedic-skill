# 同步盘 / 会议 / 播放器缓存

## 适用
「OneDrive 占了一个 G」「腾讯会议缓存好大」「网易云越来越占地方」「这些能不能删」

## 一条铁律

> **客户端自己的数据目录 ≠ 可删缓存。** 先分清三类：

| 类型 | 特征 | 处置 |
|---|---|---|
| cache | logs / ListSync / Update / Cache | 可清，会自动重建 |
| config | settings / 场景配置 / 登录态 | **不要删**，删了要重新配置或登录 |
| data | 云端文件的本地副本、下载的歌曲/视频、录制文件 | 只迁移，不删 |

## Step 1: 只读取证

```powershell
.\engine\winmedic.ps1 probe --set workloads
```

看对应 `workload.*` 条目的 `items`：每条都带 `kind` 与体积。

## Step 2: OneDrive

- `logs` / `ListSync` / `Update` 是缓存，可清；清完客户端会自己重建
- `settings` 是登录态与设置，**不要删**
- **云端文件不在这个目录**，删本地缓存放心，不会丢文件
- 想彻底重装：设置里「取消链接此电脑」，而不是删目录

## Step 3: 腾讯会议 / 网易云 / OBS

| 软件 | 可清 | 不要动 |
|---|---|---|
| 腾讯会议 | 日志、临时文件、旧安装包 | 若开了「本地录制」，录制文件可能在同目录，删前确认 |
| 网易云音乐 | `Cache`（流媒体） | 下载的音乐在另一个「下载目录」，删缓存不影响 |
| OBS | — | `obs-studio` 里是场景与**推流密钥**，外传=账号被盗 |

## Step 4: 清理方式

优先用客户端自带的「清理缓存」入口（能精确到它自己认为可删的部分）。
手工清时：**先退出程序**，**用重命名代替删除**（`logs` → `logs.bak`），确认无副作用再删。

## Step 5: 报告

给出「哪个软件 / 哪一类（cache/config/data）/ 多大 / 建议怎么处理」。

## 红线

- 不删 `settings`、`*.db`、`*.sqlite`
- 不删可能存放录制/下载内容的目录，除非用户确认
- 不在客户端运行时清缓存
