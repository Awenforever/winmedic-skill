# 终端安全体检

## 适用
「帮我看看电脑安全吗」「是不是中毒了」「防护开没开」「要不要装杀毒」。

## 原则：只读体检，不擅自「加固」

**任何关闭/开启安全功能的动作都必须用户明确同意。** 尤其不要为了「提升性能」关 Defender。

## Step 1: 只读取证

```powershell
.\engine\winmedic.ps1 probe --set security
```

读 `probe.security-posture`：
- `verdict`：ok / attention / risk
- `issues`：具体问题清单
- `defender`：实时保护、病毒库日期与天数、篡改防护、排除项数量
- `firewall`：三个配置文件是否都开启
- `bitlocker`：系统盘是否受保护
- `hardening`：SMB1、安全启动、管理员组人数、Guest 是否启用

## Step 2: 解读优先级

| 发现 | 严重度 | 说明 |
|---|---|---|
| 实时保护关闭 | 高 | 先确认是不是被第三方杀软接管，别直接开回来打架 |
| 病毒库 > 7 天 | 中 | 联网后更新即可 |
| 防火墙全关 | 高 | 公共网络下风险明显 |
| 系统盘未加密 | 取决于场景 | 笔记本易丢失才有必要，台式机可接受 |
| 管理员组 > 3 人 | 中 | 逐个确认是否本人 |
| Guest 启用 | 高 | 应关闭 |
| SMB1 启用 | 中 | 老设备兼容需要时才开 |

## Step 3: 排除项要当回事

`defender.exclusionPathCount` 不为 0 时，**逐条看是不是用户自己加的**。
异常排除项（尤其整盘排除、临时目录排除）是恶意软件常见手法。

## Step 4: 建议口径

- 先给结论（ok / attention / risk），再给证据，最后给建议
- 建议要区分「必须修」与「看场景」
- **不推销第三方杀软**

## 红线

- 不关闭 Defender / 防火墙 / 篡改防护
- 不清除 Defender 的检测历史（那是证据）
- 不运行来源不明的「安全检测工具」
