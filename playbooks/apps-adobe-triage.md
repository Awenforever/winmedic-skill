# Adobe（Photoshop / Premiere）

## 适用
「PS 提示暂存盘已满」「Premiere 预览卡」「Adobe 缓存占空间」「C 盘被 Adobe 吃满」

## Step 1: 只读取证

```powershell
.\engine\winmedic.ps1 probe --set workloads
.\engine\winmedic.ps1 relocate
```

## Step 2: Photoshop 暂存盘（最常见的误区）

**暂存盘是热数据，应该放在最快的盘（通常 C 盘 SSD）。**
把它搬到机械盘 = 每次操作都在等磁盘。

| 症状 | 原因 | 处置 |
|---|---|---|
| 「暂存盘已满」但磁盘还有几百 G | 暂存盘所在盘小，或单文件过大 | 编辑 → 首选项 → 暂存盘，**增加**一个盘（不要只换） |
| 打开大图就卡 | 暂存盘在机械盘 | 把 C 盘（SSD）设为第一个暂存盘 |
| 暂存文件残留几十 G | PS 异常退出 | 正常退出 PS 后即可回收；仍残留再清临时目录 |

```
编辑 → 首选项 → 暂存盘：勾选多个盘，顺序 = 优先级
推荐：第一个 = NVMe 系统盘，第二个 = 其他 SSD，永远不要把 HDD 放第一位
```

## Step 3: Premiere 媒体缓存

- 位置：编辑 → 首选项 → 媒体缓存（默认在 `%APPDATA%\Adobe\Common\Media Cache Files`）
- **也是热数据**：编辑时高频读写，放 SSD
- 它会在项目关闭后自动回收；定期用「删除未使用的媒体缓存文件」清理
- 缓存目录里还有 `Media Cache Database`，一起动才会生效

## Step 4: 什么时候才该搬

只有以下情况才考虑把 Adobe 缓存搬到别的盘：

1. 系统盘确实太小（< 50 GB 可用）
2. 目标盘同样是 **SSD**

搬到机械盘 = 用体验换空间，需明确告知用户。

## Step 5: 报告

给出「暂存盘/缓存当前在哪个盘、介质是什么、建议放哪、为什么」。

## 红线

- 不把暂存盘放机械盘
- 不在 Adobe 程序运行时清缓存
- 不删 `.prproj` / `.psd` 工程文件
