# 备份策略与验证

## 适用
「我有备份吗」「怎么备份比较稳」「备份到哪」「能不能恢复」。

## 铁律：备份的价值只在「能恢复」时成立

没验证过的备份约等于没有备份。

## Step 1: 只读取证

```powershell
.\engine\winmedic.ps1 probe --set backup
```

看 `probe.backup-status`：
- `level`：none / weak / ok
- `sources`：已识别的备份来源
- `fileHistory` / `oneDrive` / `systemImage` / `restorePointCount` / `shadowCopyCount`

## Step 2: 分清「系统可恢复」与「数据可恢复」

| 机制 | 能救什么 | 不能救什么 |
|---|---|---|
| 系统还原点 | 系统配置、驱动、注册表 | **个人文件** |
| 卷影副本 | 误删/误改的文件（「以前的版本」） | 磁盘故障 |
| 文件历史记录 | 用户库中的文件历史版本 | 系统状态 |
| OneDrive 文件夹备份 | 桌面/文档/图片的云端副本 | 未同步完成的文件 |
| 系统映像 | 整机（含系统） | 映像之后的新数据 |

**只有「关机外的独立副本」才算真正防丢。**

## Step 3: 推荐的最小可行方案

```
重要数据 -> 同步盘（自动、实时）
           + 外置盘 / NAS（每周，防同步误删）
           + 关键文件加密后异地（每月）
系统盘   -> 系统映像或还原点（每月或大改前）
```

**3-2-1 原则**：3 份副本、2 种介质、1 份异地。个人机至少做到 2 份。

## Step 4: 验证恢复（必做）

1. 随机挑 3 个文件，从备份里恢复一份到临时目录
2. 打开确认内容完整
3. 记录验证日期

## Step 5: 报告

给出「当前 level → 缺什么 → 最小补法 → 怎么验证」，不要只推荐买硬盘。

## 红线

- 不把唯一备份放在与被备份数据同一块物理盘
- 不在没有第二份时「清理」备份目录
- 不建议关闭系统保护来省空间（那是最后的救急手段）
