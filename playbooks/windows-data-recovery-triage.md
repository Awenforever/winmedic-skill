# 数据恢复分诊

## 适用
「误删的文件能找回吗」「回收站清空了」「硬盘里的资料没了」。

> **第一原则：能不动就不动。** 误删后在原盘继续写入，会覆盖可恢复的数据块。

## Step 1: 立即停止写入

- 不要往出问题的那块盘装恢复软件
- 不要把恢复软件的目标目录设成原盘
- 系统盘误删严重时，**先关机**，把盘挂到别的机器上再处理

## Step 2: 判断删除方式

| 情况 | 可恢复性 | 首选手段 |
|---|---|---|
| 回收站里还在 | 高 | 直接还原 |
| 回收站已清空 | 中 | 卷影副本 / 「以前的版本」 |
| Shift+Delete | 中 | 卷影副本，或专业恢复工具 |
| 格式化 | 中低 | 专业工具，别再用该盘 |
| SSD 且已 TRIM | 低 | TRIM 会真正擦除，尽早停用 |

## Step 3: 先用系统自带能力

```powershell
.\engine\winmedic.ps1 probe --set recovery
```

看 `probe.recovery-readiness`：
- `shadowCopies.count` > 0 → 右键文件夹「属性 → 以前的版本」有机会找回
- `restorePoints.count` > 0 → 系统还原点（只回滚系统状态，**不恢复个人文件**）

**注意：系统还原点不备份用户文档**，别给用户错误期待。

## Step 4: 专业工具（在原盘只读模式下）

原则：**恢复到另一块盘**，绝不在原盘写出。
选择工具时看是否支持：只读扫描、按文件类型恢复、可预览。

## Step 5: 报告

明确回答：**还有没有机会 / 应该立刻做什么 / 不应该做什么**。
不要说「应该能恢复」这种空话。
