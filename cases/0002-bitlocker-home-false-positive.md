# 病例 0002：家庭版被报「BitLocker 未保护」

## 1. 症状

- 用户原话：「说我磁盘没加密，但我这是家庭版」
- 触发条件：在 Windows 家庭版上跑安全体检
- 误判过的方向：差点建议用户去开 BitLocker（家庭版没有完整功能）

## 2. 环境

| 项 | 值 |
|---|---|
| 系统 | Windows 11 家庭版（26300） |
| 采集方式 | remote:<别名>，后本地复现 |

## 3. 采集（证据）

```powershell
winmedic.ps1 probe --set security
```

```
osCaption = Microsoft Windows 11 家庭版
bitlocker.supported = false
```

## 4. 假设与排除

| 假设 | 判据 | 结果 |
|---|---|---|
| 用户真的没开加密 | 家庭版不支持完整 BitLocker | 排除（前提错误） |
| 探针把「不支持」当成「未保护」 | osCaption 含「家庭」 | **支持** |

## 5. 处置

| 动作 | 影响面 | 可回滚 |
|---|---|---|
| 新增 `Test-BitLockerSupported`，Home/家庭 时标 `suppressed` | 仅体检报告 | 是 |

## 6. 结果

- 是否解决：是，报告改为「平台不支持，已抑制」
- 验证方式：家庭版与专业版对照

## 7. 教训

- **「没做」和「做不了」是两件事**：安全项必须先判断平台能力
- 误报比漏报更伤信任
