# 病例 0003：远端脚本直接退出，没有任何输出

## 1. 症状

- 用户原话：「远端跑你的脚本没反应」
- 触发条件：把引擎解压到远端后直接执行

## 2. 环境

| 项 | 值 |
|---|---|
| 主机 | 远端笔记本（Win11 家庭版） |
| 采集方式 | remote（手工 scp 部署） |

## 3. 采集（证据）

```powershell
powershell -NoProfile -File <engine>\winmedic.ps1 doctor
# 输出：无法加载文件 ... 未对文件进行数字签名 ... UnauthorizedAccess
```

## 4. 假设与排除

| 假设 | 判据 | 结果 |
|---|---|---|
| 脚本编码坏了 | 本地同一文件正常 | 排除 |
| **执行策略限制** | 报错明确提到执行策略 | **支持** |
| 中文乱码导致解析失败 | 报错与编码无关 | 排除（后续单独发现） |

## 5. 处置

| 动作 | 影响面 | 可回滚 |
|---|---|---|
| 远端会话内 `Set-ExecutionPolicy -Scope Process Bypass` | 仅当前进程 | 是 |
| 同时设 `[Console]::OutputEncoding = UTF8` | 仅当前进程 | 是 |

## 6. 结果

- 是否解决：是，远端采集成功（首次 38.7 s，预热 16.8 s）
- 残留问题：临时目录需清理（已固化为默认清理）

## 7. 教训

- 远程执行必须显式 Bypass，不能假设目标机策略宽松
- 两条已固化进 `New-RemoteStageScript`
