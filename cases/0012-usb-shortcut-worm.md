# 病例 0012：U 盘文件夹快捷方式病毒（DrvSvcsrMgrsvr.exe）

## 1. 症状

- U 盘（F:，57 GB FAT32）根目录出现隐藏目录 `￿`（U+FFFF）和快捷方式 `Unnamed volume (57GB).lnk`
- 用户原有文件夹/文件从根目录「消失」，实际上被移进了隐藏目录
- 主机未见异常表现，火绒实时防护开启

## 2. 环境

| 项 | 值 |
|---|---|
| 主机 | DESKTOP-CN7P93M（ustc-wjh），Windows 11，管理员 |
| 安全软件 | 火绒（HipsDaemon 运行中），Windows Defender 实时防护关闭 |
| 介质 | F:，FAT32，57.28 GB，无 `autorun.inf` |

## 3. 采集（只读）

### 3.1 快捷方式

```
目标: C:\Windows\System32\cmd.exe
参数: /c start ￿ & start ￿\DrvSvcsrMgrsvr.exe
工作目录: G:\（本机不存在该盘符）
SHA256: 27CD90930E385F7B7886DCD025BC2AD4BC85E6015D96E991B31DFFAB6DC4D421
```

### 3.2 隐藏目录

- 49 项用户数据（16 个文件 + 33 个目录）
- 根目录原本 14 项，其中 1 项 `2026科学营报名材料` 在隐藏目录里有同名副本

### 3.3 载荷

`where /r F:\ DrvSvc*`、`*Mgrsvr*` 均无命中——**载荷文件不在盘上**。
火绒隔离区也没有今日记录；因此无法取得病毒本体哈希。

## 4. 假设与排除

| 假设 | 判据 | 结果 |
|---|---|---|
| 主机已被植入 | Prefetch 无 `DRVSVCSRMGRSVR.EXE`；火绒运行历史 12:00–13:30 无可疑进程 | **排除** |
| 主机持久化 | Run/RunOnce、服务、计划任务均无异常 | **排除** |
| 其它盘符被感染 | C/D/E 根无隐藏单字符目录；99 个快捷方式解析后 0 个指向 cmd/powershell | **排除** |
| 蠕虫在 12:30 于本机执行 | 该时段运行历史只有系统更新类进程，无 cmd/载荷 | **不支持** |
| 感染发生在别的机器 | 盘上工件时间 12:30，但本机无执行痕迹 | **更可能** |

## 5. 处置

| 动作 | 可回滚 |
|---|---|
| 恶意快捷方式复制到 `C:\ProgramData\winmedic-quarantine\20261030-usb-f\`（含 metadata.json），校验哈希后从 U 盘删除 | 是 |
| 隐藏目录内 49 项原样移回根目录 | 是 |
| 同名冲突目录先移到 `_recovered_20261030`，再按「无覆盖合并」处理（228 文件新增，0 覆盖） | 是 |
| 删除空隐藏目录与 230 个空目录 | 否（均为空目录） |
| 清理 7 个 Office 锁文件、`.Spotlight-V100`、6 个 macOS `._*` 文件 | 否（元数据/临时文件） |

## 6. 结果

```
根目录: 35 个目录 / 15,211 文件 / 41.25 GB（可用 15.61 GB）
蠕虫痕迹: 隐藏目录 0 / .lnk 0 / autorun 0 / 脚本 0
数据抽样: 20/20 可读；合并目录 981 文件 / 12.84 GB
隔离区: 快捷方式原件哈希校验一致
```

## 7. 教训

1. **快捷方式病毒的核心是「移动」不是「加密」**：用户数据几乎总在隐藏目录里，先还原再谈清除，顺序不能反
2. **同盘移动不消耗空间**：先按「无覆盖」把 49 项移回，再处理同名目录，避免 47 GB 级复制把盘塞满
3. **载荷缺失时不要编造哈希**：只按行为特征（lnk 参数、隐藏目录命名、载荷名）定性，并明确说明无法取样本
4. **判断「是否蔓延」要看执行痕迹**，不是看盘上有没有文件：Prefetch、安全软件运行历史、持久化三件套
5. 打开 U 盘从导航栏点盘符，不要双击盘内文件夹图标——这类病毒只靠「诱导点击」

## 8. 追加样本（第二支 U 盘，2026-10-29 感染）

同一台主机上又插入第二支 57 GB FAT32 U 盘，形态完全一致：

| 项 | 值 |
|---|---|
| 工件时间 | 2026-10-29 15:49 |
| 根目录 | 仅 `System Volume Information` + 隐藏目录 `￿` + 恶意 `.lnk` |
| 快捷方式 SHA256 | `9F628132E1630167...`（参数同上，指向 `DrvSvcsrMgrsvr.exe`） |
| 隐藏目录内容 | 16 项（6 目录 + 10 文件），49.94 GB |
| 载荷 | **仍不存在**（`where /r F:\ DrvSvc*` 零命中） |
| 主机执行痕迹 | 10-29 15:30–16:10 无任何可疑进程；Prefetch 无 `DRVSVCSRMGRSVR` |

处置与第一支一致：快捷方式隔离到 `C:\ProgramData\winmedic-quarantine\20261029-usb-f\`，16 项原样搬回根目录（0 冲突、0 失败），删除空隐藏目录与 2 个 Office 锁文件。

结果：根目录 7 个目录 / 2,111 文件 / 49.94 GB，抽样 10/10 可读，`.lnk` 0、隐藏目录 0。

结论：**连续两天两支盘被同一形态感染，而主机两次都没有执行痕迹** —— 感染源更可能在另一台机器上，且仍在活动。

## 9. 第三支 U 盘（2026-11-03，载荷本体出现）

| 项 | 值 |
|---|---|
| 盘符 | F:，FAT32，57.3 GB |
| 快捷方式 | `Unnamed volume (57GB).lnk` |
| 快捷方式 SHA256 | `959D7E9FBF7E0A9A676C2E36D28A1322336E6E6E16B9A2454D365702F61CF377`（新变种） |
| 参数 | `cmd.exe /c start ￿ & start ￿\DrvSvcsrMgrsvr.exe`，工作目录 `G:\` |
| 隐藏目录 | `￿`（U+FFFF），17 项（6 目录 + 11 文件） |
| **载荷** | **本次盘上出现 `DrvSvcsrMgrsvr.exe`**（前两支盘均无） |
| 载荷取样 | **失败**：复制到隔离区时未落地（疑似被火绒实时防护拦截/锁定），未取得哈希 |
| 主机痕迹 | Prefetch 无 `DRVSVC*`；Run/服务/计划任务无相关项 |

处置：

1. 快捷方式复制到 `C:\ProgramData\winmedic-quarantine\20261103-usb-f\`，哈希校验一致后从盘上删除
2. 16 项用户数据同盘移回根目录，0 冲突
3. 删除载荷与空隐藏目录
4. 抽样 3 个文件可读；根目录 7 目录 / 10 文件 / 可用 7.3 GB

教训：

- 载荷终于出现，但**没能取出样本**：复制被拦截时不要直接删，应先尝试改扩展名/独占读取，或交由安全软件隔离区取样本
- 连续三支盘、同一台主机、三种 lnk 哈希，主机三次都无执行痕迹 → **感染源在另一台仍在活动的机器上**

### 火绒勒索诱饵（重要发现）

根目录出现两个隐藏目录，一度被当作可疑项：

- 名称：前导空格的 TOOL204、ZSTORE995
- 属性：Hidden, System, Directory, NotContentIndexed
- 类型：目录联接（junction）
- 目标：F:\ProgramData\Huorong\Sysdiag\BaitRoot

这是火绒的勒索诱饵目录，里面 10 个随机名文件是诱饵，故意不可删除。它们不是病毒，不要删。

引擎已修正：probe --set usb 跳过重解析点/联接，不会把诱饵目录当蠕虫工件。

教训：

- 盘上删不掉的隐藏目录，先看 Target，可能是安全软件的诱饵，而不是权限问题
- 载荷被占用时仍可在盘上取哈希；不要为了取样关闭防护
